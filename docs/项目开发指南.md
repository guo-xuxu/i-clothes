## 1. 这个项目是干什么的

**i-clothes 智能穿搭助手**：用户上传照片或写文字描述，AI 给出个性化穿搭建议。
支持多轮聊天、意图路由（要推荐还是闲聊）、会话历史。

**技术形态（双服务架构）**——一句话：**业务归 Java，AI 归 Python，两个服务用 HTTP 通信**。

```
浏览器（Vue3 前端，不关心后端是谁）
   │  /api/*（对外契约）
   ▼
Java 业务后端 :8080  ──────────────┐
├─ 会话/消息 CRUD → PostgreSQL     │  RestClient
├─ Redis：会话写锁 + 限流          │
├─ 校验/错误处理/伺服前端页面       ▼
└─────────────────────►  Python AI-Agent 服务 :8000
                        └─ LangGraph：意图路由 → 闲聊 / 推荐 → 千问/DeepSeek
```

**为什么这样分**：AI 生态（LangGraph、工具调用、RAG）是 Python 的强项；业务工程
（事务、并发、中间件、团队熟悉度）是 Java 的强项。各用所长。**数据归 Java 管，
Python 只做推理、不存任何东西（无状态）**，所以 Python 服务可以随便加实例横向扩展。

## 3. 一次消息的完整旅程（以 POST /api/chat 为例）

你在前端输入"帮我推荐上班通勤的穿搭"点发送：

1. **前端** `api.js` → `POST /api/chat`，JSON：`{"conversation_id": "...", "message": "...", "images": []}`
2. **Java `ChatController`**：校验（图片格式/数量/大小、消息非空）→ 不过就 400
3. **Java `RateLimiter`**：这个 IP 这个分钟内超过 60 次 → 429
4. **Java `ChatService`**：
   - 会话不存在 → 自动新建（PG 插入）
   - 从 PG 取最近 20 条历史
   - Redis 会话写锁（`conversation:{id}:lock`，别人正在写就等，超 3 秒 → 503）
   - **调 Python**：`POST /api/agent/chat`，把 `{message, images, history}` 发过去
5. **Python `agent.py`** → LangGraph 工作流：
   - `intent_router` 判断意图：有图必推荐 / 命中"推荐/穿搭/婚礼…"→ 推荐 / 否则闲聊
   - 推荐 →（有图先调千问分析体征）→ DeepSeek 生成建议
   - 闲聊 → DeepSeek 多轮对话
   - 返回 `{"reply": "...", "intent": "recommend"}`（1~60 秒）
6. **Java** 收到回复 → 事务内落库（用户消息 + 助手消息）→ 裁剪历史到 50 条 → 刷新会话时间 → 释放锁
7. 前端把回复渲染成气泡，旁边带"穿搭模式/对话模式"标签

**贯穿原则：Java 管数据、Python 管推理、契约（字段名/错误码）是两边的宪法。**

## 4. 本地怎么跑

环境已装好（JDK 21 在 `D:\language\java21`，Maven、PG 16、Memurai/Redis 都是常驻服务）。
**新开一个终端**（环境变量生效），按顺序：

```powershell
# 1) Python Agent（:8000）—— 注意它启动时会自动拉起 Phoenix 追踪服务
cd D:\code\i-clothes
D:\code\i-clothes\.conda\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

# 2) Java 后端（:8080）—— 先确保 PG(5432)、Redis(6379) 在跑
cd D:\code\i-clothes
mvn -f iclothes-server/pom.xml package -DskipTests   # 首次或改代码后打包
java -jar iclothes-server\target\iclothes-server-0.1.0.jar

# 3) 前端开发模式（:5173，自动代理 /api 到 8080）
cd D:\code\i-clothes\frontend
npm.cmd run dev
```

浏览器开 `http://127.0.0.1:5173`。验证：`http://127.0.0.1:8080/api/health` 应返回
`{"status":"ok","qianwen_configured":true}`。

> 改代码后：Java 改完要重新 `mvn package` 再重启；Python 有 `--reload` 自动生效；
> 前端 vite 有热更新。停止服务看 `常用指令` 文件（停端口命令）。

## 5. 想改东西？改哪里、怎么验证

| 想改什么 | 改哪个文件 | 怎么验证 |
|---|---|---|
| 意图路由关键词 | `app/graph/nodes/intent_router.py` 的 `RECOMMEND_KEYWORDS` / `CHAT_KEYWORDS` | 跑 Python 契约测试（路由 6 用例在里面） |
| 闲聊的说话风格 | `app/graph/nodes/chat_reply.py` 的 `CHAT_SYSTEM_PROMPT` | 起服务发条消息看回复 |
| 推荐结果的格式/口吻 | `app/graph/nodes/recommend_outfit.py` 的 `RECOMMEND_PROMPT`（"没有照片的情况下…"那句在这里） | 同上 |
| 限流阈值（60 次/分） | `iclothes-server/src/main/resources/application.yml` → `iclothes.rate-limit.per-minute` | 起 Java 后连续请求看是否 429 |
| 上传限制（3 张/5MB） | 同文件 → `iclothes.upload.max-count` / `max-size-mb` | 传 4 张图应 400 |
| 前端代理端口 | `frontend/vite.config.js` | 起 vite 看页面能不能请求通 |
| 换模型/key | `app/repositories/model_repo.py`（模型名/key 从 `.env` 读）；Java 侧基本不用动 | 起服务发消息 |
| 加一个新接口 | Java：`controller/` 建类 + `service/` + `dto/`，Python 一般不用动 | 写 MockMvc 测试 + curl 验证 |
| **改表结构** | ⚠️ 不能改 `V1__init.sql`（Flyway 已应用过），**新建 `V2__xxx.sql`** + 对应实体/Mapper | 跑集成测试 `RepositoryIT` |

## 6. 必须知道的约定与坑

1. **接口键名是 snake_case**：`application.yml` 里 `spring.jackson.property-naming-strategy: SNAKE_CASE`
   全局生效。Java DTO 里写 `conversationId`，线上就是 `conversation_id`——**前端按 snake_case 读**，别改这条。
2. **错误体永远是 `{"detail": "中文消息"}`**：400（参数校验）/ 404（会话不存在）/ 502（AI 服务挂了）/
   503（并发锁等待超时）/ 429（限流）。前端 `api.js` 只认 `detail` 字段。
3. **LLM 请求不自动重试**：AI 调用很贵，发出去就不重试，失败直接 502 提示用户——防止重复扣费。
4. **会话写锁 TTL 是 5 秒且不续期**：一次 AI 调用可能超过 5 秒，理论上锁会提前过期。这是已知权衡
   （同会话并发罕见 + 503 兜底），别单独改，除非你同时想清楚并发语义。
5. **`mvn test` 不会跑集成测试**（类名 `*IT` 是 Surefire 约定）：要显式
   `mvn -f iclothes-server/pom.xml test -Dtest=RepositoryIT`（连真实 PG 的 `iclothes_test` 库）。
6. **`stringtype=unspecified`** 在 datasource URL 里，是让 JSONB 字段能接收字符串绑定——别删。
7. **时间戳是 epoch 秒数字**（不是 ISO 字符串）：前端按 `ts*1000` 显示，改了会变 NaN。
8. **Python 服务的 `.env`** 里有真实 API key，契约测试是 mock 的，**跑测试不会花钱**；
   但起服务发消息会真实调用千问/DeepSeek（花钱，按次数）。
9. **harness/脚本进程的 JAVA_HOME 是旧快照**：如果你在自动化环境跑 mvn 报 JAVA_HOME 错，
   先执行 `$env:JAVA_HOME='D:\language\java21'`；自己开的终端不用管。

## 8. 术语表（新手速查）

| 术语 | 意思 |
|---|---|
| 契约（contract） | 两个服务/前后端之间约定的接口格式，改一边必须同步改另一边 |
| 意图路由 | 判断用户想"要推荐"还是"随便聊聊"（现在是关键词规则） |
| LangGraph | Python 的 AI 工作流框架，把"分析→推荐"编排成一张图 |
| MyBatis-Plus | Java 的 ORM，`BaseMapper` 帮你免写增删改查 SQL |
| Flyway | 数据库版本管理：`V1__init.sql` 建表，以后改表加 `V2__...` |
| JSONB | PostgreSQL 的 JSON 列类型（消息里存的图片列表） |
| 虚拟线程 | Java 21 特性，让高并发请求更省资源 |
| NX EX | Redis 命令参数：只有键不存在才设置 + 5 秒过期（做锁用） |
| fail-open | 依赖挂了（如 Redis）时放行而不是拒绝，保证服务不中断 |
| Pull Request | 分支合并进主分支前的"申请+审阅"流程 |
| snake_case / camelCase | `conversation_id` vs `conversationId` 两种命名风格 |
