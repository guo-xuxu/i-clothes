# 知识库落盘数据

本目录存放构建产物（见 docs/RAG知识图谱规划.md 3.2「落盘清单」）。

## 目录内容

| 路径 | 说明 |
|------|------|
| `graph/graph.json` | 知识图谱（节点/边 + 构建元数据），networkx 序列化产物 |
| `graph/history/` | 可选：图谱构建历史快照 |
| `chunks/` | 可选：切块后的文本中间产物（最终向量写入 PG，不入库文件） |

## 说明

- 图谱是构建产物，运行时由 `retrieve/graph_store.py` 载入内存缓存。
- 向量不在本地落盘（写入 PG `knowledge_chunks` 表），本地仅保留原始切块便于调试。
- 本目录随构建自动生成，通常无需手动编辑。
