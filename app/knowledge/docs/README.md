# 内置穿搭知识文档

本目录存放喂给知识图谱 + 向量库的穿搭知识 markdown。

## 知识维度约定（9 维度）

按 `docs/RAG知识图谱规划.md` 3.1.1 约定，穿搭知识分 **9 个正交维度**，每个维度一个子目录：

| # | 维度 | 目录名 | 解决什么 | 关键判断 |
|---|------|--------|---------|---------|
| ① | 廓形与版型 | `silhouette/` | 衣服穿在身上「骨架对不对」 | 肩线、腰线、松紧、是否合身 |
| ② | 身材比例与修饰 | `body-shape/` | 如何扬长避短、显高显瘦 | 体型分类、上下身比例、焦点位置 |
| ③ | 面料与材质 | `fabric/` | 质感与季节适配 | 垂坠感、挺括度、厚薄、肌理 |
| ④ | 风格定位 | `style/` | 整体人设是否统一 | 休闲/通勤/复古/街头/极简等 |
| ⑤ | 图案与纹理 | `pattern/` | 视觉节奏与繁简平衡 | 条纹/格纹/碎花/纯色的搭配禁忌 |
| ⑥ | 配饰与点缀 | `accessory/` | 收尾与精致度 | 鞋、包、腰带、首饰、帽、丝巾 |
| ⑦ | 场合与季节（TPO） | `occasion/` | 穿得「对不对地方」 | 时间/地点/场合、叠穿与温度 |
| ⑧ | 颜色搭配 | `color/` | 配色是否和谐 | 色相/明度/冷暖、不超过三色 |
| ⑨ | 肤色与个人色彩 | `skin-tone/` | 颜色适不适合「我」 | 冷暖皮、四季型、显白/显脏 |

> 注意：⑧ 颜色搭配（颜色之间怎么配）与 ⑨ 肤色与个人色彩（哪些颜色适合某类肤色）
> 是两个独立维度；⑧ 不并入 ⑦（TPO），⑨ 不并入 ②（身材）。

## 每个维度目录里放什么

- 一个维度目录下可放 **一篇或多篇** markdown（`.md`）或纯文本（`.txt`）。
- 文件命名建议用中文描述性名称，如 `婚礼着装.md`、`条纹与格纹的搭配.md`。

## 写作要求（面向 RAG 抽取）

1. **可抽三元组**：多用「实体 + 关系 + 目标」的陈述句，
   例如「婚礼 → 建议穿 → 西装」「梨形身材 → 适合 → A 字裙」，
   避免抒情、模糊表述（如「好看就行」）。
2. **可切块检索**：每小节主题单一、知识点颗粒小、可独立成段。
3. **原创表述**：用自己的话整理，避免整篇复制有版权的网络文章。

## 导入方式

```bash
python -m app.knowledge.build.import_docs <文件或目录> [--dry-run]
```

- 导入单篇：`python -m app.knowledge.build.import_docs app/knowledge/docs/occasion/婚礼着装.md`
- 导入全部：`python -m app.knowledge.build.import_docs app/knowledge/docs`
