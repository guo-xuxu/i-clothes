# 职场通勤着装

> 来源：faqs.tw《場合穿搭》、Blinkscoop《How To Dress For Occasions》、Adorn Closet《Dress for Success》

职场着装的核心是在舒适与专业之间取得平衡，根据公司文化与 dress code 调整正式程度。

## 职场 dress code 分级

商务正式（Business Professional）是最正式的职场着装，穿剪裁合身的西装、保守配色、极简配饰，适用于重要会议、面试和正式商务场合。商务休闲（Business Casual）比商务正式更放松但仍精致，穿西装外套配西裤或裙子、衬衫、职业连衣裙。

## 职场着装的基本要点

上衣选衬衫、针织衫、简单 T 恤；下装选直筒裤、及膝裙；外套选西装外套；鞋选乐福鞋、低跟鞋；配色以中性色为主。避免过低胸、过短、运动裤等过度休闲单品。

## 商务休闲的搭配

卡其裤或西裤配衬衫或 Polo 衫、乐福鞋是男装商务休闲的基础；女装穿西装裤、裙装或连衣裙配衬衫或针织衫、闭口低跟鞋。始终倾向精致整洁的外表，避免牛仔裤、运动鞋（除非办公室允许）。

## 通勤的通用原则

合身比价格更重要，花在剪裁上比花在 logo 上更有价值。鞋子是除脸之外最先被注意的，正式皮鞋、低跟鞋能提升专业度。不确定时宁可略微正式一些，宁过勿欠。西装外套是通勤最好用的单品，能瞬间提升任何造型的精致度。
