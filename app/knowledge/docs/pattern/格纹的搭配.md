# 格纹的搭配

> 来源：搜狐《按图索衣》、搜狐《看着高级的中年女人》

格纹种类繁多，不同格纹传递不同风格信号，是经典且易出错的图案。

## 常见格纹类型

苏格兰格纹是经典格纹代表，三粗一细的交叉图案、颜色众多，适宜大多数人。威尔士亲王格纹由细小的深浅过渡黑灰白线条构成，细腻雅致、高贵内敛。千鸟格（犬牙花纹）沉稳厚重、视觉冲击力强，适合做冬装外套。维希格纹双色交错、其中一色通常是白色，清爽自然、具夏日法式气息。大方格子量感最大、膨胀感强、易显胖。

## 格纹的风格定位

格纹自带复古滤镜。苏格兰格复古英伦，千鸟格优雅知性复古，威尔士格绅士通勤低调，维希格清新田园，棋盘格街头潮流。格纹西装配纯色直筒裤、格纹半裙配纯色针织或白衬衫都是经典搭配。

## 格纹的搭配原则

格纹与纯色单品搭配最稳妥，用纯色上衣、同色系鞋包中和大面积格纹的繁杂，做到繁简平衡、甜而不腻。避免与条纹、碎花叠穿（易杂乱）。小格纹显瘦、大格纹显胖。

## 格纹的配色

复古色如墨绿、深蓝适合显成熟的格纹；黑白格子简约百搭；粉色格纹衬衫搭黑色长裙或白裤，色彩鲜明又层次丰富。格子裤复古有文艺感，大面积格纹让裤装更独特。
